## Overview

Albino 3 is a full-featured software synthesizer with four oscillators, dual multi-mode filters, a 6×6 modulation matrix, arpeggiator, and three on-board effect types for versatile synthesis.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Rob Papen Albino** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Oscillators** | Four VA oscillators each with 14 waveform shapes and octave tuning |
| **Dual Filters** | Two independent multi-mode filters with parallel and serial routing |
| **6x6 Mod Matrix** | 36-slot matrix connecting any of six sources to any of six targets |
| **On-Board FX** | Delay, chorus, and reverb effect inserts within the synthesizer |
